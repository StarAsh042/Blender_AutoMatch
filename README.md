# Blender 高低模配对重命名工具

一个Blender插件,用于智能配对并重命名高低模物体,支持多种配对算法和灵活的命名配置。

## 主要功能

- 🔍 **三种智能配对算法**:
  - 简单算法:基于距离和面数,适合物体分布均匀的场景
  - 聚类算法:先聚类再配对,适合多角色等聚类特征场景
  - 体积算法:考虑体积相似度,适合复杂场景

- 🎯 **自动识别高低模**:基于面数自动判断哪个是高模、哪个是低模

- 📝 **批量重命名**:统一格式命名(BakePoly_001_High/Low)

- ↩️ **可撤销**:原始名称记录在物体自定义属性中,一键恢复

- 🎨 **自动原点校正**:将物体原点设置到包围盒中心

- 📁 **集合管理**:自动移动到Baking集合

## 快速开始

### 安装

1. 下载插件压缩包
2. 在Blender中打开 `编辑` → `偏好设置` → `插件` → `安装`
3. 选择下载的zip文件并安装
4. 启用插件:搜索"高低模匹配"

### 使用方法

1. 选中要处理的网格物体(至少2个)
2. 在3D视图侧边栏打开"高低模匹配"面板
3. 选择合适的配对算法(默认简单模式)
4. 点击"执行配对重命名"按钮
5. 等待配对完成,查看结果

### 基本工作流程

```
选中物体 → 选择算法 → 执行配对 → 自动重命名 → 移动到Baking集合
```

## 配对算法详解

### 1. 简单算法 (SIMPLE)

**原理**:基于物体中心点距离和面数进行配对

**适用场景**:
- 物体分布均匀
- 物体数量较少(<50个)
- 快速配对需求

**参数**:
- 最大配对距离:控制物体中心点的最大允许距离
- 面数比例阈值:高模与低模的最小面数比例

### 2. 聚类算法 (CLUSTER)

**原理**:先按空间位置聚类,然后在每个聚类内进行配对

**适用场景**:
- 物体有明显的聚类特征(如多个角色模型)
- 物体分布不均匀
- 需要避免跨聚类错误配对

**参数**:
- 聚类半径:控制聚类的距离阈值
- 最大配对距离:聚类内的配对距离限制
- 面数比例阈值:高模与低模的最小面数比例

### 3. 体积算法 (VOLUME)

**原理**:综合考虑距离和体积相似度进行配对

**适用场景**:
- 需要考虑物体体积相似度的复杂场景
- 物体大小差异较大
- 需要更精确的配对质量

**参数**:
- 最大配对距离:物体中心点的最大允许距离
- 体积比例范围:高模与低模的体积比例范围
- 面数比例阈值:高模与低模的最小面数比例

## 命名规则

插件使用统一的命名格式:

```
{前缀}{序号}_{后缀}
```

**示例**:
- 高模: `BakePoly_001_High`
- 低模: `BakePoly_001_Low`

**参数**:
- 前缀:默认为 `BakePoly_`
- 序号位数:默认为3位数字(001, 002, ...)
- 序号:自动递增,从Baking集合最大序号+1开始
- 后缀:`High`(高模) 或 `Low`(低模)

**序号如何计算**:只在Baking集合内匹配 `{前缀}{序号位数}_High/Low` 形式的名称,取其最大序号+1。
例如集合内已有 `BakePoly_007_High`,则下次从 `008` 开始。

## 撤销配对

选中已配对的物体,点击"撤销配对":

1. 从物体的 `original_name` 自定义属性读取原始名称并恢复
2. 清理 `original_name`、`pairing_prefix` 属性
3. 若原始名称已被其他物体占用,则跳过该物体并给出提示

也可以直接用 Blender 的撤销(Ctrl+Z)。

## 最佳实践

### 配对前准备

1. **清理场景**:删除不需要的物体,避免干扰
2. **检查物体**:确保物体类型为MESH且有面
3. **调整原点**:建议开启"自动设置原点"功能

### 算法选择建议

- **快速配对**:使用简单算法
- **多角色场景**:使用聚类算法
- **复杂模型**:使用体积算法
- **不确定**:先尝试简单算法,再根据结果调整

### 参数调优技巧

1. **配对距离**:根据场景大小调整,单位为世界坐标
2. **面数比例**:通常高模面数是低模的2-10倍
3. **聚类半径**:略大于角色间的距离
4. **体积比例**:通常在0.5-2.0之间

### 避免错误配对

- 确保物体位置相对稳定
- 避免重叠过近的物体
- 合理设置配对距离
- 使用聚类算法避免跨聚类配对

## 技术细节

### 数据结构

配对结果格式:
```python
pairs = [
    (高模对象, 低模对象, 距离),
    (高模对象, 低模对象, 距离),
    ...
]
```

说明:
- 简单/聚类算法:第三项为两物体包围盒中心的距离,越小越好
- 体积算法:第三项同样为距离,但候选排序综合了距离与体积相似度(体积比例越接近1评分越高)

## 常见问题

### Q: 为什么有些物体没有被配对?
A: 可能原因:
- 距离超过最大配对距离
- 面数比例不符合要求
- 已经被其他物体配对

### Q: 如何撤销配对?
A: 选中已配对的物体,点击"撤销配对"按钮,会从物体的 `original_name` 属性恢复原始名称并清理配对属性;
原始名称若已被占用会跳过该物体并提示。也可以直接使用 Blender 的撤销(Ctrl+Z)。

### Q: 配对结果不满意怎么办?
A: 建议:
1. 调整配对参数
2. 更换配对算法
3. 检查物体位置和大小
